## Priority Issues

**P1 — Actions tab non-functional on first use**
All three "Open With" buttons toast "Set X path in Settings first." Delete shows "not yet implemented." Dead zone.
Fix: Disable visually when unconfigured, add "Configure in Settings →" link.
Command: `$impeccable clarify`

**P1 — No keyboard shortcuts for power-user actions**
Only Ctrl/Cmd+N and Escape. No shortcuts for tabs, checklist, gallery, bases, pipeline.
Fix: Add 1/2/3 for tabs, G for gallery, B for bases, arrow keys for pipeline.
Command: `$impeccable harden`

**P2 — Generic error messages**
"Could not load project data" doesn't tell users what went wrong or how to fix it.
Fix: Specific messages with recovery actions.
Command: `$impeccable clarify`

**P2 — No focus-visible styles**
Keyboard users can't see focused elements.
Fix: Add :focus-visible with accent-colored outline.
Command: `$impeccable harden`

**P3 — Gallery header control bar**
7 controls simultaneously visible. Cognitive overload.
Fix: Collapse filters behind toggle.
Command: `$impeccable distill`

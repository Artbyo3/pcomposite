# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

3D artists and game developers managing asset pipelines across multiple tools (Blender, Substance Painter, Unity). Primary workflow: modeling → texturing → exporting → integration → packaging.

## Product Purpose

Centralize and visualize the 3D asset pipeline. Replace scattered folders, spreadsheets, and manual checks with one app that tracks where every asset is in the pipeline, manages export versioning, and coordinates tool handoffs.

## Positioning

Pipeline-aware asset management — not a generic file manager, but a tool that understands the Blender→Painter→Unity→Package→Upload workflow and routes files accordingly.

## Operating Context

Desktop app (Electron) running alongside Blender, Substance Painter, and Unity. Users switch between these tools frequently. The app must be fast, keyboard-friendly, and visually scannable at a glance.

## Capabilities and Constraints

- Folder-based project structure with per-tool routing
- Export versioning with per-target tracking
- Bases Library for avatar base management
- Pipeline stage tracking with visual progress
- Checklist auto-generated from pipeline stages
- Dark technical theme (near-black bg, chartreuse accent)
- Space Mono + Syne font pairing

## Brand Commitments

- Name: PCOMPOSITE
- Dark technical aesthetic is intentional
- Chartreuse accent (#e8ff47) is the brand color

## Product Principles

1. Pipeline clarity over file management
2. Tool-aware, not tool-agnostic
3. Visual status at a glance
4. Keyboard-friendly for power users
